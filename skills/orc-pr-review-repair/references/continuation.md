# Continue an interrupted PR repair run

Read during preparation when prior PR records or the caller indicate interrupted review, repair, validation, publication or history recording. Use actual state and the existing [report contracts](./report-contracts.md), not a new history protocol. Resume requires the same identity, authorization, run ID, ledger and cumulative ten-attempt accounting. A fresh session or outer issue-to-PR handoff is not a fresh budget.

## Recover the reservation and scope

Delegate read-only reconciliation of all paginated PR records, full original axis reports, judge ledgers, repair-start/summary/escalation receipts, pinned base, expected/local/remote/reviewed SHAs, index/working tree and entire outgoing range. Validate record markers against actual PR/git state and record contents; deduplicate verified records by identity, not count of comments. Every verified repair-start consumes its attempt even if edits, delivery or summaries failed. Missing/conflicting records or unexplained work pauses for exact history/scope reconciliation before edits. Keep history away from the next fresh reviewer and both axes.

For optional archived sources, reread confirmed archive/main files and reconcile current inventory/content against the original complete move receipt **plus authorized repair-owned changes**. Keep the archive path fixed. Inspect each affected code/test/document change against the reserved IDs, correction class and approved intent; retain changed/unchanged document dispositions and preservation evidence. Unrecorded archive drift is not permission to rewrite requirements or replay sync/archive. Ordinary PRs need no archive context.

## Finish only the incomplete attempt

1. **Reserved, edits partial:** reuse the verified repair-start and its reserved count. Independently inspect completed safe edits and finish only its authorized corrections. Investigate changed findings; new consequential intent or expanded scope requires a scoped decision, not automatic edits. No second reservation for an agent retry.
2. **Edits complete, validation missing/failed:** establish actual owned diff, regressions and required checks. For archived sources include code/archive/main-spec alignment and affected document/spec validation using direct files or disposable copies. Incomplete evidence blocks delivery; do not count an old report as current validation.
3. **Signed commit exists, push missing/uncertain:** verify signing/DCO, contents and entire outgoing range, then query the exact remote. Reuse accepted commits and do only the missing normal push on verified ancestry. Unexpected/diverged refs or failed signatures pause; preserve safe work, never force push or rewrite automatically.
4. **Push confirmed, summary missing/uncertain:** verify delivered SHA and actual content/alignment, search records for the linked summary before posting. Reuse a matching verified record; otherwise post/verify only the missing summary linked to the original start. Comment failure leaves history incomplete and must be reported directly.
5. **Attempt delivered and recorded:** only then start a fresh history-free full-diff review and history-aware judgment with all prior actionable IDs accounted for. Renew affected validation and final-head gates at the delivered/reviewed SHA. At attempt ten this final review can finish or escalate, never reserve attempt eleven.

An interrupted review/judgment has no acceptance; repeat only that missing complete review/judgment after aligned state, without inventing a repair reservation. Already complete delivery/history is observed, not replayed. Preserve unresolved IDs and all resolution evidence. The ordinary threshold still governs any next new correction; retries and document work share the reserved attempt.

## Return the continuation evidence

Extend existing summary/escalation/final reports with:

- Same PR/run/round, verified start link, recovered cumulative count and complete ledger/history links; completed versus remaining attempt operations.
- Expected, local, remote, previously reviewed and final delivered/reviewed/gate SHAs, actual owned diff and independent validation/content receipts.
- For archived sources: confirmed path/current complete inventory, original finalization sync acceptance and move receipt, authorized repair content changes, current code/archive/main-spec alignment and affected validation.
- Signed commit, normal-push and summary/final-record URL/ID receipts; exact missing evidence or conflicting state with question/options/consequences/recommendation.

Return this full evidence to an outer issue-to-PR coordinator, not merely a completion label. It re-establishes final-head gates and reports sync/archive, included evidence and final reviewed SHA separately. Archived means packaged for review, not merged. No prompt report is a native checkpoint, durable transaction or proof of model obedience.
